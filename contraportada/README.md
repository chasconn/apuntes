# Contraportada · Felices para siempre 🌸

Contraportada imprimible para el cuaderno de la **Asamblea 2026 "Felices para siempre"**,
diseñada a juego con la portada (mismo estilo, colores y animalitos del paraíso).

## Archivo
- `contraportada.html` — página lista para usar. Es **un solo archivo** (la imagen de fondo
  va incrustada), así que se abre en cualquier computador, tablet o teléfono sin internet.

## Cómo usarla
1. Abre `contraportada.html` con un doble clic (se abre en el navegador).
2. Puedes **escribir los datos directamente en pantalla** (nombre, edad, ciudad,
   congregación, grupo, fecha, texto favorito y teléfono). Lo que escribas se guarda
   solo en ese navegador.
3. Toca el botón **🖨️ Imprimir / Guardar PDF** (arriba a la derecha) para imprimirla
   o guardarla como PDF.
   - En el diálogo de impresión elige tamaño **Carta**, márgenes **Ninguno** y
     activa **Gráficos de fondo** para que salgan los colores.
4. Si prefieres, imprímela en blanco y que tu hija rellene los espacios **a mano**.

Pensada para imprimirse en una sola hoja tamaño carta (8.5 × 11").
